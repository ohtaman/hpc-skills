# TSUBAME4.0 ミニキャンプ固有設定

基本的な TSUBAME4.0 の使い方は `tsubame4` スキルを参照。
このスキルはイベント固有の差分設定のみを記載する。

```
  ※ 配布スライドに tge-mc2509 という誤記あり。実機の id で確認した正しい値は tge-mc2609
ARID:        8372  (ノード予約枠)
prior キュー利用期間: 2026-09-11 10:00 〜 2026-09-18 18:00  (15ノード、12グループ27名で共有)
ノード予約期間:       2026-09-18 10:00〜17:55  (8ノード)
共有ストレージ:       /gs/bs/tge-mc2609  (10TB quota、チーム別サブディレクトリ)
```

## ジョブ投入の制約

通常の従量制ジョブ（`-g` のみ）は**投入できない**。
必ず以下のいずれかを使う:

```bash
# 定額制キュー（prior）: イベント期間中のみ有効
qsub -g <グループ> -q prior job.sh

# 予約ノード（AR）: 指定された日時・枠のみ
qsub -g <グループ> -ar <ARID> job.sh

# お試し実行（グループ指定なし・2ノード・3分以内）: 濫用しない
qsub job.sh
```

AR の確認:

```bash
t4-user-info compute ar     # 自分のグループの予約一覧
qrstat -ar <ARID>           # 予約の詳細（ノード数・期間）
```

## ストレージ

```
共有ストレージ: /gs/bs/<グループ>      (グループ全体で共有)
個人ディレクトリ: /gs/bs/<グループ>/<チーム名 or ユーザ>/
```

- **他チームのディレクトリへの書き込み・削除は絶対禁止**
- 読み取りも必要な範囲にとどめる

## 参加者間の作法

- グループあたり同時実行は **1〜2 ノードが目安**
- 多ノード実行は Slack 等で示し合わせて譲り合う
- インタラクティブノード（`iqrsh`）は **1人1セッションのみ**。終了し忘れに注意
